# Colony Alert

One key switches the colony between normal and alert status. Each status remembers every colonist's allowed area, schedule, work priorities, apparel, food, drug and reading policies and hostility response, plus tame animals' and colony mechanoids' allowed areas, so a raid setup is set once and restored with a key press. A red border and an ALERT banner show while alert status is on, and the Work, Schedule, Assign, Animals and Mechs tabs are marked as showing the alert settings. Every part of this can be turned off in the mod settings.
